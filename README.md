# Titanic Survival Predictor 🚢

A Flask web app that predicts whether a Titanic passenger survived or not using Machine Learning models (Logistic Regression, Random Forest, XGBoost).

Live Demo: [https://titanic-predictor-app.onrender.com](https://titanic-predictor-app.onrender.com)

---

## 📦 Features
- Predicts survival based on passenger details (class, age, fare, etc.).
- Select different models: Logistic Regression, Random Forest, XGBoost.
- Deployed live using Render.

---

## 🚀 Tech Stack
- **Backend:** Flask + Python
- **ML Models:** Scikit-learn, XGBoost
- **Deployment:** Render
